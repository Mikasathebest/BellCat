# BellCat 2.1.2

BellCat is a multi-stage focus timer and reminder app for macOS, Windows, and Linux.

## What's new

- The project README now defaults to English, with a dedicated [Simplified Chinese README](https://github.com/Mikasathebest/BellCat/blob/main/README.zh-CN.md).
- Windows now includes a guided per-user installer: `BellCat-2.1.2-Windows-x64-Setup.exe`.
- The installer adds Start Menu and uninstall entries, offers an optional desktop shortcut, and can launch BellCat when setup finishes.
- Installation does not require administrator access.
- The portable Windows ZIP remains available.

## Downloads

- macOS Apple Silicon: `BellCat-2.1.2-macOS-arm64.dmg` or ZIP
- Windows x64 installer: `BellCat-2.1.2-Windows-x64-Setup.exe`
- Windows x64 portable: `BellCat-Windows-x64.zip`
- Linux x64: `BellCat-Linux-x64.tar.gz`

The macOS build is ad-hoc signed but not Apple-notarized. If Gatekeeper blocks the first launch, Control-click BellCat in Finder and choose **Open**.
