# BellCat 2.5.10

## Improvements

- Centers the timer ring and cat control when no side panel is open.
- Keeps the cat control aligned with the ring while a side panel is visible.
- Automatically keeps upcoming reminders collapsed by default.
- Hides both the reminder card and its expand control when there are no enabled reminders in the next six months.
- Adds one-click reminder expansion and collapse.
- Returns the ring to the center after closing reminders or stage colors.
- Moves the quote below the language and settings controls.
- Applies the same responsive layout to Windows and Linux.

## Downloads

- macOS Apple Silicon: `BellCat-2.5.10-macOS-arm64.dmg` or ZIP
- Windows x64 installer: `BellCat-2.5.10-Windows-x64-Setup.exe`
- Linux x64: `BellCat-Linux-x64.tar.gz`
