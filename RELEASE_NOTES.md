# BellCat 2.5.4

This release tightens the focus-screen layout and makes custom routines more precise.

## Improvements

- Moves the **+** action immediately beside the task selector.
- Keeps task and white-noise dropdown indicators close to their labels.
- Supports keyboard entry for stage hours, minutes, and seconds.
- Lets you type every stage name directly; new stages default to **Other**.
- Replaces stage removal controls with a clear red **×**.
- Moves music selection beside playback and white-noise controls.
- Removes the ring interaction hint from the clock center.
- Shows the selected stage's color palette in the open area to the right of the ring.
- Preserves and automatically migrates existing minute-based custom tasks.
