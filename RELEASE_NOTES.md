# BellCat 2.5.7

## Improvements

- Moves Reset closer to the centered cat timer control.
- Removes the permanent empty column to the right of the timer ring.
- Shows the compact color panel only after a ring stage is selected.
- Narrows the color panel and reduces the macOS window's minimum width.
- Applies the same compact layout behavior to Windows and Linux.

## Downloads

- macOS Apple Silicon: `BellCat-2.5.7-macOS-arm64.dmg` or ZIP
- Windows x64 installer: `BellCat-2.5.7-Windows-x64-Setup.exe`
- Linux x64: `BellCat-Linux-x64.tar.gz`
