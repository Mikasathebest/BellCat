# BellCat for Windows and Linux

This implementation uses Python's native Tk GUI and provides BellCat's core features on non-Apple platforms: multi-stage tasks, an interactive segmented timer ring, reminders, light/dark themes, persistent settings, and seven interface languages.

Run from source:

```bash
python3 bellcat.py
```

On Ubuntu/Debian, install `python3-tk` and `libnotify-bin`. Release binaries are built by GitHub Actions with PyInstaller.
